# HPC-NRC Applications — DFTB+ Research and HPC Workflow

This repository documents my research, installation, deployment, testing,
benchmarking and visualization work using **DFTB+ (Density Functional Tight
Binding Plus)** in a VMware-based mini-HPC environment.

The repository is divided into two major sections:

1. **DFTBPlus-HPC-Complete-Workflow**  
   The practical implementation of the project.

2. **dftbplus-research-docs**  
   The research and theoretical documentation behind DFTB+.

Together, these sections document the complete journey from understanding
DFTB+ theoretically to compiling it, running molecular simulations with MPI,
benchmarking its performance and visualizing molecular structures.
