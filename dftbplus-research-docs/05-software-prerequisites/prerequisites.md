# 5. Software Prerequisites for DFTB+

> **This is the most critical section for anyone preparing to build DFTB+.**  
> Below is a numbered list (1–25) of every software dependency, tool, and library required or recommended for a complete DFTB+ installation.

---

## 5.1 Required Prerequisites (Must-Have)

These are **mandatory** — DFTB+ cannot be compiled without them.

---

### 1. Fortran Compiler (Fortran 2018 Support Required)

| Detail       | Value                                       |
|-------------|---------------------------------------------|
| **Purpose** | DFTB+ is written in modern Fortran           |
| **Minimum** | Must support Fortran 2018 and OpenMP 4.0     |
| **Recommended** | GNU gfortran ≥ 13.2, Intel ifort ≥ 2021.5, or NAG ≥ 7.2 |
| **Our Cluster** | Use `gfortran` from the GNU Compiler Collection (GCC) |

```bash
# Check version
gfortran --version
```

---

### 2. C Compiler

| Detail       | Value                                       |
|-------------|---------------------------------------------|
| **Purpose** | Required for the build system and C API      |
| **Recommended** | GNU gcc ≥ 13.2 (match your Fortran compiler version) |
| **Our Cluster** | Use `gcc` |

```bash
# Check version
gcc --version
```

---

### 3. C++ Compiler

| Detail       | Value                                       |
|-------------|---------------------------------------------|
| **Purpose** | Required for ChIMES, ELSI+PEXSI extensions, and C++ API tests |
| **Recommended** | GNU g++ ≥ 13.2 |
| **Our Cluster** | Use `g++` |

```bash
# Check version
g++ --version
```

---

### 4. CMake (Build System Generator)

| Detail       | Value                                       |
|-------------|---------------------------------------------|
| **Purpose** | Configures the build, detects libraries, generates Makefiles |
| **Minimum** | CMake ≥ 3.22                                |
| **Website** | [cmake.org](https://cmake.org)               |

```bash
# Check version
cmake --version
```

---

### 5. GNU Make

| Detail       | Value                                       |
|-------------|---------------------------------------------|
| **Purpose** | Executes the build instructions generated by CMake |
| **Minimum** | Any modern version (≥ 4.0)                  |

```bash
# Check version
make --version
```

---

### 6. Python (Build-Time Requirement)

| Detail       | Value                                       |
|-------------|---------------------------------------------|
| **Purpose** | DFTB+ source preprocessor (fypp) requires Python |
| **Minimum** | Python ≥ 3.7                                 |
| **Note**    | Only needed during compilation, not at runtime |

```bash
# Check version
python3 --version
```

---

### 7. LAPACK (Linear Algebra PACKage)

| Detail       | Value                                       |
|-------------|---------------------------------------------|
| **Purpose** | Dense linear algebra routines (eigenvalue problems, matrix decompositions) |
| **Options** | Reference LAPACK, OpenBLAS (includes LAPACK), or Intel MKL |
| **Our Cluster** | Use **OpenBLAS** (includes both BLAS and LAPACK) |

---

### 8. BLAS (Basic Linear Algebra Subprograms)

| Detail       | Value                                       |
|-------------|---------------------------------------------|
| **Purpose** | Low-level matrix and vector operations        |
| **Options** | Reference BLAS, OpenBLAS, or Intel MKL        |
| **Our Cluster** | Use **OpenBLAS** (provides optimised BLAS + LAPACK in one package) |

```bash
# Install on Ubuntu/Debian
sudo apt install libopenblas-dev
```

---

### 9. Git (Version Control)

| Detail       | Value                                       |
|-------------|---------------------------------------------|
| **Purpose** | Clone the DFTB+ source code and initialise submodules |
| **Minimum** | Git ≥ 2.0                                    |

```bash
# Check version
git --version
```

---

### 10. pkg-config

| Detail       | Value                                       |
|-------------|---------------------------------------------|
| **Purpose** | Helps CMake locate installed libraries        |
| **Note**    | Usually pre-installed on Linux systems        |

```bash
# Check
pkg-config --version
```

---

## 5.2 Strongly Recommended Prerequisites

These are **not strictly required** but are highly recommended for a useful installation.

---

### 11. MPI (Message Passing Interface)

| Detail       | Value                                       |
|-------------|---------------------------------------------|
| **Purpose** | Enables distributed-memory parallel execution across nodes |
| **Options** | OpenMPI (recommended), MPICH, Intel MPI      |
| **Our Cluster** | Use **OpenMPI** — better for small, heterogeneous clusters |
| **Required For** | Multi-node calculations                   |

```bash
# Install on Ubuntu/Debian
sudo apt install openmpi-bin libopenmpi-dev

# Check version
mpirun --version
```

---

### 12. ScaLAPACK (Scalable LAPACK)

| Detail       | Value                                       |
|-------------|---------------------------------------------|
| **Purpose** | Parallel linear algebra for MPI builds        |
| **Required When** | Building with `-DWITH_MPI=YES`         |
| **Options** | Netlib ScaLAPACK, Intel MKL ScaLAPACK, or build from source |

```bash
# Install on Ubuntu/Debian
sudo apt install libscalapack-openmpi-dev
```

---

### 13. fypp (Fortran Preprocessor)

| Detail       | Value                                       |
|-------------|---------------------------------------------|
| **Purpose** | Metaprogramming preprocessor used by DFTB+ source code |
| **Install** | Included as a submodule, or install via pip   |

```bash
pip install fypp
```

---

### 14. ARPACK-ng (Arnoldi Package)

| Detail       | Value                                       |
|-------------|---------------------------------------------|
| **Purpose** | Eigenvalue solver required for TD-DFTB excited state calculations |
| **Parallel** | Use **PARPACK** (parallel version) for MPI builds |

```bash
# Install on Ubuntu/Debian
sudo apt install libarpack2-dev libparpack2-dev
```

---

## 5.3 Optional Prerequisites (Feature-Dependent)

These enable advanced features. Install only if needed.

---

### 15. ELSI Library

| Detail       | Value                                       |
|-------------|---------------------------------------------|
| **Purpose** | Alternative eigensolvers for large-scale MPI-parallel calculations |
| **When** | Systems with > 1,000 atoms on many nodes      |
| **Note** | For our small cluster, this is likely **not needed** |

---

### 16. PLUMED2

| Detail       | Value                                       |
|-------------|---------------------------------------------|
| **Purpose** | Enhanced sampling methods (metadynamics, umbrella sampling) |
| **When** | Studying rare events or free energy landscapes |

---

### 17. MAGMA (Matrix Algebra on GPU)

| Detail       | Value                                       |
|-------------|---------------------------------------------|
| **Purpose** | GPU-accelerated linear algebra for single-node GPU runs |
| **When** | You have NVIDIA GPUs available                |
| **Our Cluster** | **Not applicable** (no GPUs)              |

---

### 18. TBLite

| Detail       | Value                                       |
|-------------|---------------------------------------------|
| **Purpose** | Enables xTB-type Hamiltonians (GFN1-xTB, GFN2-xTB) |
| **When** | You want to use xTB methods instead of standard DFTB |

---

### 19. simple-dftd3 / dftd4

| Detail       | Value                                       |
|-------------|---------------------------------------------|
| **Purpose** | Grimme's D3/D4 dispersion corrections         |
| **When** | Van der Waals interactions are important in your system |

---

### 20. ChIMES (Chebyshev Interaction Model)

| Detail       | Value                                       |
|-------------|---------------------------------------------|
| **Purpose** | Machine-learned reactive potentials           |
| **When** | Combining ML potentials with DFTB+            |

---

## 5.4 Visualisation and Analysis Tools

These are **not needed for compilation** but essential for working with DFTB+ results.

---

### 21. VMD (Visual Molecular Dynamics)

| Detail       | Value                                       |
|-------------|---------------------------------------------|
| **Purpose** | Visualise molecular structures and MD trajectories |
| **Format** | Reads XYZ files output by DFTB+               |
| **Website** | [ks.uiuc.edu/Research/vmd](https://www.ks.uiuc.edu/Research/vmd/) |

---

### 22. OVITO (Open Visualisation Tool)

| Detail       | Value                                       |
|-------------|---------------------------------------------|
| **Purpose** | Powerful scientific visualisation and analysis |
| **Features** | Structural analysis (CNA, DXA), rendering, Python scripting |
| **Website** | [ovito.org](https://www.ovito.org)            |

---

### 23. ASE (Atomic Simulation Environment)

| Detail       | Value                                       |
|-------------|---------------------------------------------|
| **Purpose** | Python library for setting up, running, and analysing simulations |
| **Features** | Can drive DFTB+ directly as a calculator      |
| **Install** | `pip install ase`                             |

---

### 24. Jmol

| Detail       | Value                                       |
|-------------|---------------------------------------------|
| **Purpose** | Java-based open-source molecular viewer       |
| **Features** | Cross-platform, web-deployable, reads XYZ     |
| **Website** | [jmol.sourceforge.net](http://jmol.sourceforge.net/) |

---

### 25. gnuplot / matplotlib

| Detail       | Value                                       |
|-------------|---------------------------------------------|
| **Purpose** | Plotting band structures, DOS, energy profiles, and other data |
| **Options** | `gnuplot` (terminal-based) or `matplotlib` (Python) |
| **Install** | `sudo apt install gnuplot` or `pip install matplotlib` |

---

## 5.6 Dependency Graph

The relationship between prerequisites:

```
DFTB+ Binary
├── Compilers (gfortran, gcc, g++)
│   └── Must all be from the same toolchain version
├── Build System
│   ├── CMake (≥ 3.22)
│   ├── GNU Make
│   ├── Python (≥ 3.7)
│   └── fypp (Fortran preprocessor)
├── Core Libraries
│   └── OpenBLAS (provides BLAS + LAPACK)
├── Parallel Libraries (if MPI build)
│   ├── OpenMPI
│   └── ScaLAPACK
└── Optional Libraries
    ├── ARPACK-ng (for TD-DFTB)
    ├── ELSI (for large-scale)
    ├── PLUMED2 (for metadynamics)
    └── TBLite (for xTB methods)
```
